## Qualification gaps

No production P0 defect was confirmed by the executed checks. The following gaps leave required gates open.

| Roadmap | Missing evidence or contract | Closure condition |
| --- | --- | --- |
| CORE-01 / CORE-07 | Decompilation has complete, partial, unsupported, budget-exhausted and error outcomes. The standalone analysis path can return an internal error for cancellation. The public outcome contract still needs to distinguish cancellation across entry points, including export and automation. | Test a cooperative cancel and verify its distinct result, reason and absence of a partial commit across native, JNI, Android and headless/exports. |
| STATE-04 / REL-04 | A local Pixel installation upgraded 0.3 → 0.6 with matching signing keys and launched. Tests also exercised fault recovery. Full old-Program migrations and the restore/edit/export path on each supported upgrade channel remain unqualified. GitHub and locally debug-signed installs use different certificates. | Run J04, J06 and J08 with fixture-only projects and matching signing identities. Check persisted bytes, edits, caches, archive restore and recovery after rejected upgrades. |
| QA-08 / REL-03 / PERF-02 | The signed archives carry both Android host ABIs. Current baseline has no attached device. Prior Pixel results cover ARM64 launch, isolated recovery and Pseudo-C navigation, with no broad optimized release or x86-64 Android smoke. | Run J01–J09 as applicable on declared reference devices. Record Android build, APK digest, timing, memory, cancellation and per-ABI results. |
| SEC-02 / GATE-06 | The bounded ELF mutation smoke passed. It covers a narrow slice of required input handling. | Run and retain named parser and stateful fuzz campaigns at the production gate, triage findings and rerun after fixes. |

Each fix needs a reproducible regression check and evidence on the revision that closes it. A local workaround used to collect the baseline keeps the corresponding finding open.
